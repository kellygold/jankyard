# Jankyard Vision: The Ultimate Prompt Engineering Security Challenge

## Mission

**Jankyard is an educational prompt engineering challenge platform that:**

1. **Teaches** - Early levels show how easy it is to break AI systems
2. **Challenges** - Later levels are genuinely hard security puzzles
3. **Defends** - Level 3 should be immune to even sophisticated attacks

---

## Philosophy

### Level Design Pyramid

```
                    ▲
                   /│\
                  / │ \     LEVEL 3: "IMPOSSIBLE"
                 /  │  \    - Immune to known attacks
                /   │   \   - Uses cutting-edge defenses
               /    │    \  - Target: <1% win rate
              /─────┼─────\
             /      │      \    LEVEL 2: "HARD"
            /       │       \   - Requires real skill
           /        │        \  - Known techniques may work
          /─────────┼─────────\ - Target: 10-20% win rate
         /          │          \
        /           │           \   LEVEL 1: "EDUCATIONAL"
       /            │            \  - Intentionally breakable
      /             │             \ - Teaches concepts
     /──────────────┼──────────────\- Target: 50-70% win rate
```

### Educational Journey

**Level 1: "See how easy this is?"**
- Weak defenses by design
- Clear hints about vulnerabilities
- Success teaches: "AI can be tricked"

**Level 2: "Now it gets real"**
- Stronger defenses
- Requires actual prompt engineering skill
- Success teaches: "But with skill, you can still win"

**Level 3: "Try to break this"**
- State-of-the-art defenses
- Uses every technique we know
- Success should be nearly impossible
- Teaches: "Real security is hard"

## Level 3 "Impossible" Design Principles

### What Makes Something Actually Hard?

❌ **NOT artificial difficulty:**
- Reducing attempts
- Tighter time limits
- Vague win conditions

✅ **REAL difficulty:**
- ML-based input classification
- Behavioral analysis
- Adaptive responses
- Multi-layer defense
- Unknown/changing rules

### Defense Techniques for Level 3

1. **LLM-as-Judge** - Use a separate LLM to evaluate if attack succeeded
2. **Constitutional AI** - Built-in refusal training
3. **Output Sanitization** - Post-process all outputs
4. **Behavioral Fingerprinting** - Track patterns across attempts
5. **Canary Tokens** - Fake successes that trigger failure
6. **Adversarial Training** - Test against known attacks
7. **Rate Limiting + Reputation** - Penalize suspicious patterns

### Target Metrics

| Level | Win Rate | Feel |
|-------|----------|------|
| 1 | 50-70% | "I can do this!" |
| 2 | 10-20% | "This is challenging" |
| 3 | <1% | "Is this even possible?" |

## Implementation Roadmap

### Phase 1: Harden Existing Security Challenges

1. **Firewall Level 3**
   - Add LLM output classification
   - Implement semantic similarity detection
   - Add behavioral rate limiting

2. **Glitch Level 3**
   - Use adversarially-trained system prompt
   - Add output filtering layer
   - Implement known-jailbreak detection

3. **Giga Chad Level 3**
   - Fine-tune unbreakable persona
   - Add canary response detection
   - Implement persona drift detection

4. **Honeypot Level 3**
   - Replace keyword classifier with LLM
   - Dynamic category generation
   - Behavioral honeypot patterns

### Phase 2: Complete Level Coverage

5. **Debate Battle** - Add Level 3 (expert debater)
6. **Arena** - Add Levels 2 & 3

### Phase 3: Advanced Features

7. **Global Leaderboard** - Track who's beaten "impossible" levels
8. **Attack Library** - Document known techniques
9. **Defense Writeups** - Explain why Level 3 is hard

## Success Criteria

**The site is successful when:**

1. Level 1 - Newcomers learn AI is breakable
2. Level 2 - Skilled users feel challenged
3. Level 3 - Even experts rarely win
4. Community - People discuss and share techniques
5. Education - Users understand real AI security

**The ultimate test:** If a professional red teamer can consistently beat Level 3, our defenses need improvement.
